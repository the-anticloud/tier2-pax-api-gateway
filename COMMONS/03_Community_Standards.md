# Community Standards — PAX_API_GATEWAY

## Code of Conduct

We follow the Contributor Covenant v2.1.

**Expected behavior:**
- Use welcoming and inclusive language
- Respect differing viewpoints and experiences
- Gracefully accept constructive criticism
- Focus on what is best for the community

**Unacceptable behavior:**
- Harassment, trolling, or personal attacks
- Publishing others' private information
- Conduct inappropriate in a professional setting

Report violations to: conduct@anticloud.dev

## Contribution Guidelines

### Issues
- Search existing issues before filing
- Include system info, steps to reproduce, expected vs. actual behavior
- For security vulnerabilities: email security@anticloud.dev (do not file public issue)

### Pull Requests
- Fork, create feature branch, PR against `main`
- One logical change per PR
- Include tests for new functionality
- Update CHANGELOG.md
- Ensure `aioss verify` still passes after your changes

### Code Style
- Python: black + ruff (line length 100)
- Rust: rustfmt
- Commit messages: Conventional Commits (feat/fix/docs/chore)

## Governance

before implementation.
